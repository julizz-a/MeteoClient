В данном проекте предоставлена демонстрация хранения, обработки и анализа метеоданных. При необходимости, проект MeteoClient может быть подключен так, что программа будет получать реальные данные по TCP от метеостанций-симуляторов. Таким образом, архитектура позволяет легко переключаться между тестовым режимом и реальной работой по сети. O_o
